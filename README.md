#  U.S. States Game

A Python Turtle-based game where the player tries to guess all 50 U.S. states and their locations on a map.

## 🎮 How It Works

* A blank map of the United States is displayed.
* Enter the name of a U.S. state.
* If the answer is correct, the state name is placed on the map.
* The game continues until all 50 states are guessed.
* Type `Exit` to stop the game.

* Turtle
* Pandas
* CSV

## 🚀 How to Run

1. Clone or download the repository.
2. Make sure Python is installed.
3. Install Pandas if needed:
   `pip install pandas`
4. Run:

```bash
python main.py
```
